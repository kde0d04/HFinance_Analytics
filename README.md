# 💼 HFinance Analytics

A Streamlit-based financial analytics dashboard powered by Python, Pandas, NumPy, Plotly, Seaborn, and Agentic AI concepts.  
This project is part of my AI & Data Science learning journey and is designed to showcase **financial data visualization, processing, and agentic reasoning**.

---

## 🚀 Features
- **Interactive Dashboard** built with Streamlit
- **Data Processing Layer**: Liquidity Ratio, Profit Margin, Revenue per Employee
- **Visualization Layer**: Plotly 2D/3D charts, Seaborn distributions, Matplotlib plots
- **Agentic AI Layer**: ReAct-style agent integration for financial reasoning
- **Export Options**: Generate reports in multiple formats
